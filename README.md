## The entry

> "I simulated this elevator ride 40,000 times, and in every single one, I still had nothing to say to you."

One robot, mid-ride, confesses it brute-forced the whole encounter
40,000 times in simulation — and still could not find a single thing
to say. Machine logic (exhaustive simulation) meets the most human
awkwardness there is: silence in a lift.

## How it works

`main.ts` (Node 22, no dependencies, no build step) writes the single
line to `/output/entry.txt`. The program is fully deterministic: the
same line, every run.

```sh
node main.ts
cat /output/entry.txt
```
